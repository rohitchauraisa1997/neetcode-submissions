## How this repo is organized

```
Data Structures & Algorithms/   NeetCode solutions (the sync writes here)
codility/                       Codility solutions
scripts/                        organize.py, make_pdf.sh, pdf_order.py, pdf_index.py
pdf/                            solutions.pdf (generated, for printing)
```

`Data Structures & Algorithms/` follows the order of NeetCode's
[Algorithms & Data Structures for Beginners](https://neetcode.io/courses/dsa-for-beginners/0) course:

```
Data Structures & Algorithms/<NN Section>/<N Lesson>/<problem>/<problem>.py
                              01 Arrays / 3 Stacks / minimum-stack / ...
```

- Each solution starts with its problem statement. Extra approaches point back to it.
- `cheatsheet.py` in a section holds the general concepts for that topic.
- A `.png` next to a solution (same name) is a diagram for it.
- Problems outside the course get their own section after it (e.g. `13 Sliding Window`).

`codility/` uses the same sections as NeetCode (by the technique each task uses), without
a lesson level: `codility/<NN Section>/<task-name>/<task-name>.py`
(e.g. `codility/14 Prefix Sums/passing-cars/`). Sections the beginners course doesn't
cover use NeetCode 150 topics after it: 13 Sliding Window, 14 Prefix Sums, 15 Two Pointers,
16 Greedy, 17 Math & Geometry. Add a new task as `codility/<task-name>/` and
`scripts/organize.py` moves it into its section.

After pulling new NeetCode submissions (the sync writes them to
`Data Structures & Algorithms/<problem>/`):

```bash
python3 scripts/organize.py   # move new problems (NeetCode + Codility) into their lesson
sh scripts/make_pdf.sh        # rebuild pdf/solutions.pdf in course order
```

The PDF opens with an index (NeetCode, then Codility): tap a problem to jump to it. The same
tree is in the PDF's bookmarks, the table of contents in most PDF viewers.

## What is this?

[NeetCode.io](https://neetcode.io) is a coding interview preparation platform featuring curated problems, video solutions, and an in-browser code editor. This repository is automatically populated with your accepted (or all) solutions using the **GitHub Sync** feature.

---

## How GitHub Sync works

1. **Connect your GitHub account** on [neetcode.io/profile/github](https://neetcode.io/profile/github).
2. **Auto-commit** — every time you submit a solution on NeetCode, it is pushed here automatically (configurable by status).
3. **Bulk Sync** — push all your past solutions at once from the GitHub settings page.
4. **Manual sync** — from the submission history panel on any problem page, sync or remove individual submissions.

## Repository structure

Solutions are organized by topic folder, then problem ID. Each submission is stored as a separate file:

```
<topic-folder>/
  <problem-id>/
    submission-0.<ext>   ← first submission
    submission-1.<ext>   ← second submission
    ...
```

**Example:**
```
Data Structures & Algorithms/two-integer-sum/submission-0.py
Data Structures & Algorithms/binary-search/submission-0.ts
Python For Beginners/python-hello-world/submission-0.py
```
